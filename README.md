# Kumbu² Sync

An Obsidian plugin that keeps a local Obsidian vault in sync with a [Kumbu²](https://github.com/SCAI-NGO/kumbukumbu) vault, so notes written by agents through MCP and notes written by hand in Obsidian live in one place.

**Status:** not yet implemented. The design lives in the server repository: [`docs/obsidian-plugin-design-spec.md`](https://github.com/SCAI-NGO/kumbukumbu/blob/master/docs/obsidian-plugin-design-spec.md).

## Prerequisites

- Obsidian 1.11.4 or newer (the plugin keeps its API key in Obsidian's `SecretStorage`)
- A Kumbu² server and an API key for the device

## Installation

Once the first release is out, install it with [BRAT](https://github.com/TfTHacker/obsidian42-brat): add the beta plugin `SCAI-NGO/kumbu-obsidian`.
